# DNX Manager Updates

Repositório público utilizado exclusivamente pelo DNX Manager para distribuição e verificação automática de atualizações.

O aplicativo consulta a **última Release** uma única vez a cada inicialização. Quando existe uma versão mais recente, o usuário pode baixar e instalar o Setup oficial diretamente pelo DNX Manager.

## Padrão das Releases

- Tag: `vX.Y.Z`
- Instalador: `DNX_Manager_Setup_X.Y.Z.exe`
- O texto da Release é utilizado como notas da atualização.

> O código-fonte do DNX Manager não é armazenado neste repositório.
